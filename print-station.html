처음 한 번만: 자동 인쇄 바로가기 만들기

보통 크롬은 인쇄할 때마다 [인쇄] 버튼을 사람이 눌러야 합니다. 아래 바로가기로 열면 인쇄 창 없이 기본 프린터로 바로 나갑니다 (크롬의 자동 인쇄 모드).

  1. 기본 프린터 정하기 — 윈도우: 설정 → 블루투스 및 장치 → 프린터 및 스캐너 → 교회 프린터 → 기본값으로 설정. 같은 곳의 인쇄 기본 설정에서 양면 · 짧은 가장자리로 맞춰 두세요.
  2. 바로가기 2개 받기 — 윈도우: woori-print-setup.bat(설정용) · woori-print-station.bat(자동 인쇄) / 맥: woori-print-setup.command · woori-print-station.command 를 내려받아 바탕화면에 둡니다.
  3. 설정용으로 한 번 — setup 바로가기를 두 번 누르면 평소 크롬과 별개인 '인쇄 전용' 크롬 창이 열립니다. Google 로그인 → 이 컴퓨터 이름 적고 [이름 저장] → [시험 인쇄] → 인쇄 창에서 프린터·양면(짧은 가장자리)·A4를 맞추고 인쇄 → 창을 닫습니다. 이 설정을 자동 인쇄가 그대로 씁니다.
  4. 자동 인쇄로 열기 — 이제 station 바로가기를 두 번 누릅니다. [시험 인쇄]를 누르면 인쇄 창 없이 바로 나와야 합니다. 맥은 처음 한 번 파일을 우클릭 → 열기로 여세요.
  5. 이후에는 컴퓨터를 켤 때 바로가기만 눌러 두면 됩니다. 절전 모드가 되면 인쇄를 못 받으니, 전원 설정에서 '절전 안 함'으로 두면 좋습니다.
